ปรับปรุงล่าสุด: มีนาคม 2569
1. ผู้ควบคุมข้อมูล
JIA TRAINER CENTER สำนักงาน: The Street Ratchada ชั้น 3 กรุงเทพมหานคร
2. ข้อมูลที่เก็บ
ไฟล์ binary log จาก AED (event, CPR, ECG, impedance, system log, battery, audio, patient) ข้อมูลผู้ใช้บริการ ข้อมูลการชำระเงิน
3. วัตถุประสงค์
3.1 ถอดรหัสและสร้างรายงาน CPR
3.2 ออกใบกำกับภาษี
3.3 วิจัยและพัฒนา (De-identified)
3.4 ปรับปรุงความแม่นยำระบบ
4. การประมวลผล
ส่งไปยัง Claude API (Anthropic, Inc. สหรัฐอเมริกา) เพื่อวิเคราะห์ทางเทคนิค
5. ระยะเวลาเก็บรักษา
5.1 Decoded Report: เก็บตลอดระยะเวลาให้บริการ
5.2 ไฟล์ binary: เก็บเพื่อ decode ซ้ำ
5.3 ข้อมูลการเงิน: 5 ปีตามกฎหมายภาษี
5.4 ข้อมูลวิจัย (De-identified): ไม่มีกำหนด
6. สิทธิของท่าน
เข้าถึง แก้ไข ลบ ระงับ ถอนความยินยอม โอนข้อมูล คัดค้าน — ข้อมูลที่ de-identified แล้วไม่สามารถเรียกคืนได้
7. ความปลอดภัย
HTTPS (SSL/TLS), Encryption at Rest, Access Control, Backup
